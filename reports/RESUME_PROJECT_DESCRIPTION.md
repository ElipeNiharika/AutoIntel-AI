AI Vehicle Service, Repair & Insurance Intelligence

Role: Lead ML Engineer
Tools: Python, Pandas, Scikit-learn, XGBoost, Flask, MySQL, Joblib

Description:
- Built a production-oriented ML system predicting repair cost, repair time, and insurance claim likelihood using structured tabular datasets. Engineered features from service descriptions and parts lists, trained RandomForest and XGBoost models, and deployed via a Flask API with MySQL-backed prediction history.

Impact:
- Improved repair cost estimation accuracy, provided explainable diagnosis and rule-based parts recommendations, and delivered an admin dashboard for stakeholders.
